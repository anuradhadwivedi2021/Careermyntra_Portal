📄 Import Colleges from PDF

How it works: Upload any CAP Round / Admission PDF that has college listings like "60001 - Govt. College of Engineering, Pune". All pages will be scanned automatically, college codes & names extracted, and saved to the master database. Existing codes are updated (safe to re-upload). You can edit each record later to add District, City, University etc.

📥 Bulk Import via JSON

Format: Paste a JSON array of college objects. Each object must have college_code and college_name. Other fields are optional. If a college_code already exists, it will be updated (upsert).

Available fields: college_code, college_name, district, city, state, university, college_type, management, minority_status, autonomy_status, website, phone, address
